================================================================================
2. TARGET PERSONAS & USER JOURNEYS
================================================================================
1. AI Benchmarking Engineers & Evaluation Specialists
   - Needs: Direct head-to-head model comparison on domain-specific prompts with repeatable, isolated timing and cost calculation.
   - Pain Points: Opaque cloud benchmark aggregators (e.g. Chatbot Arena) that don't test private internal prompts, or static multiple-choice tests that ignore generative nuances.
   - compare-race Solution: Local-first sequential stopwatch or parallel race execution, complete output collection in Markdown/front-matter artefacts, deterministic tally checks, and reproducible six-axis attribution.

2. Multi-Model Agent Loop & System Architects
   - Needs: Automated selection of the best-suited LLM for critical production subtasks (e.g., coding, translation, summarisation).
   - Pain Points: Subjective impressions or relying purely on provider self-reported benchmarks that do not reflect actual latency, variance, or instruction following.
   - compare-race Solution: Evidence-aware starter judge evaluating sibling outputs across multi-dimensional rubrics, with strict refusal for unprovenanced or simulated runs.

3. Prompt Engineers & Alignment / Twin-Mode Researchers
   - Needs: Causal evaluation of prompt variations, system prompt tuning, few-shot framing, and skill activations.
   - Pain Points: Confounding prompt improvements with model variations or run-to-run stochastic variance.
   - compare-race Solution: Dedicated Twin/Clone mode (`run --twin`) fixing the model while systematically varying the variant axis across repeated runs.

4. Enterprise Tooling, Safety & Governance Compliance Officers
   - Needs: 100% offline evaluation, zero telemetry egress, permissive licensing, unprivileged process execution.
   - Pain Points: Leaking proprietary business prompts or internal data to external leaderboard endpoints; copyleft license risks.
   - compare-race Solution: 100% Local-First / Zero-Egress (INV-LOCAL-01), unprivileged RunAsInvoker operation (INV-SEC-02), 100% permissive dependencies (MIT / PSFL-2.0 audited in THIRD_PARTY_LICENSES.md), dual security response SLAs (48h acknowledgment, 5-day triage).

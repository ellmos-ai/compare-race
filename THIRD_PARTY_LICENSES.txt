1. LEVEL 1 SBOM ARCHITECTURAL GUARANTEES & RUNASINVOKER CERTIFICATION
----------------------------------------------------------------------

- Non-Elevation Security (INV-SEC-02):
  Benchmarking, token hashing, process timing, artefact recording, and starter-judge
  evaluations operate strictly in unprivileged user mode (RunAsInvoker). No
  administrative elevation or UAC prompts are required for core CLI or library execution.

- Zero-Copyleft Isolation Guarantee (INV-LIC-09):
  0% AGPL, 0% GPL, 0% LGPL. All runtime and build dependencies are 100% permissive
  (MIT, Apache-2.0, PSFL-2.0). The evidence-aware judge was independently implemented
  from concepts observed in SentinelFleet; no AGPL source was copied. No copyleft
  infection or dynamic linking licensing hazards exist across any component.

- Local-First & Zero-Egress Guarantee (INV-LOCAL-01):
  100% offline, air-gapped execution by default. Zero outbound telemetry, zero usage
  analytics, and zero background network socket activity. When external CLI adapters
  are invoked, network communication is strictly governed by user authentication.
